# TS++ Support

TS++ is experimental and currently provides community support only.

Use the [TS++ issue tracker](https://github.com/tspp-lang/tspp/issues) for
reproducible bugs and feature proposals. Search existing issues before opening a
new one and include the output of `tspp --version`, the smallest reproducer you
can make, and the exact command that produced the problem.

Questions about standard TypeScript behavior may still be better served by the
[TypeScript documentation](https://www.typescriptlang.org/docs/) because TS++
preserves TypeScript as its compatibility baseline.
