# `@tspp/example-advanced-classes`

Demonstrates the 7 modern OOP features provided by `@tspp/plugin-advanced-classes`:

1. **`field` property syntax**: Semi-auto property declaration with implicit backing storage and custom `get()`/`set()` accessors.
2. **`object` declarations**: First-class singleton instances and their types.
3. **`data class`**: Primary constructor parameter syntax with auto-synthesized `copy()`, `equals()`, and `toString()`.
4. **`with` expressions**: Non-destructive copy expression for data classes and objects.
5. **`sealed class`**: Closed type hierarchies restricted to inheritance within the declaring file.
6. **`final class` & `final` methods**: Subclassing and method override prevention.
7. **`async constructor`**: Asynchronous initialization pipeline during object instantiation.
